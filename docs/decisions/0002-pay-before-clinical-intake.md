# 0002 Payment before clinical intake

Status: locked
Date: 2026-06
Owner: Thomas, per Andrew's guidance

## Decision

Payment is collected before the clinical intake begins.

## Rationale

The clinical question set is a function of the cart. The cart has to be
resolved before the correct question set can be served.

## Consequences

Refund path needed for patients who fail clinical screening after paying.
Copy on the checkout step must set that expectation.
