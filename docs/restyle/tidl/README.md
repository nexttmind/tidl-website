# Restyle archive

This folder is a 2024 rebuild capture (Aesop category, Good Life PDP, Figma Foundations). It is not the live visual language.

Do not implement type, color, or surface from files in this folder except the two current docs:

- `10-target-tokens.md` mirrors `web/app/globals.css`
- `13-target-principles.md` is the current rule set

Everything else is historical structure capture. If a file and the CSS disagree, the CSS wins.

Retired and must not be reintroduced on the consumer site:

- Source Serif 4, Questrial, Canela, Sohne as site fonts
- Warm cream page `#F5F2ED`
- Public `/brand/peptide` or `/emails/*.html` as a scrapeable system. Those routes are deleted.
